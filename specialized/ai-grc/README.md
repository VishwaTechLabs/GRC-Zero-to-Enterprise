# AI GRC — Dedicated Module

## AI governance lifecycle

AI use case → inventory → classification → risk assessment → controls → validation →
deployment approval → monitoring → incident management → retirement.

## AI risks

- Hallucination and reliability
- Privacy/data leakage
- Prompt injection
- Insecure tool/plugin use
- Model theft
- Training-data risk
- Bias/fairness
- Lack of explainability
- Excessive autonomy
- Third-party model risk
- AI supply-chain risk
- Intellectual-property concerns
- Shadow AI
- Regulatory non-compliance
- Inadequate human oversight

## AI inventory fields

`AI ID | Use Case | Owner | Model | Provider | Data | Business Purpose | Risk Class | Human Oversight | Status`

## AI control examples

1. Approved AI-use policy.
2. AI inventory maintained.
3. High-risk use cases require formal assessment.
4. Sensitive data handling rules enforced.
5. Model validation performed.
6. Human oversight defined.
7. Security testing performed.
8. Third-party AI contracts assessed.
9. AI incidents are reported and tracked.
10. AI systems are periodically reviewed.
