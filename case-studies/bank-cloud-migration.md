# Case Study — Bank Cloud Migration

## Scenario
Bank migrates customer workloads to cloud. Assess shared responsibility, IAM, logging, encryption, backup, network segmentation, vendor risk and regulatory obligations.

## Student tasks
1. Define scope.
2. Identify assets/processes.
3. Identify risks.
4. Select controls.
5. Define evidence.
6. Assign owners.
7. Recommend treatment.
8. Prepare executive summary.
9. Identify framework mappings.
10. Defend the recommendation in a viva.
