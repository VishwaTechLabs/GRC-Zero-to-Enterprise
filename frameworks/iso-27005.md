# ISO-27005
## Purpose
Information-security risk-management guidance and risk-treatment concepts.

## GRC teaching pattern
1. Determine applicability.
2. Identify obligations/outcomes.
3. Map to risks.
4. Map risks to controls.
5. Define evidence.
6. Test controls.
7. Record gaps and remediation.
8. Report residual risk.

## Classroom exercise
Select five requirements/outcomes and map:
`Requirement → Risk → Control → Owner → Evidence → Test → Finding`.

## Source discipline
Use the current official publication or legal text for formal compliance, certification,
audit or regulatory decisions.
